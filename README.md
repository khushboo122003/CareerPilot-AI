# 🚀 CareerPilot AI

### AI-Powered Recruitment & Candidate Intelligence Platform

CareerPilot AI is an AI-powered recruitment platform designed to help recruiters analyze candidates, evaluate resumes, match candidates with job requirements, generate interview insights, and make data-driven hiring decisions.

## ✨ Key Features

### 📄 Resume Intelligence

* Upload and analyze candidate resumes.
* Extract relevant candidate information and skills.
* Generate AI-based resume insights and evaluation scores.

### 👥 Candidate Management

* Maintain candidate profiles in a centralized database.
* View candidate information, skills, education, and contact details.
* Track candidate progress throughout the recruitment process.

### 🧠 AI Candidate Evaluation

* Evaluate candidates across multiple dimensions.
* Generate scores for technical skills, communication, problem-solving, and confidence.
* Calculate an overall candidate evaluation.

### ⭐ Recruiter Feedback & Decision System

A structured recruiter evaluation system that combines AI-generated candidate insights with recruiter decision-making.

Recruiters can:

* Select a candidate from the candidate database.
* Review AI-generated resume analysis.
* View candidate evaluation scores.
* Review strengths and improvement areas.
* Receive an AI-generated recruitment recommendation.
* Make a final **Hire, Hold, or Reject** decision.
* Save the complete recruiter evaluation to the database.

The system follows the workflow:

**Resume → AI Analysis → Candidate Score → Recruiter Review → Structured Feedback → Recruiter Decision → Candidate Intelligence**

### 🎯 AI Recruiter Shortlisting

* Compare multiple candidates against a job description.
* Identify matching skills and missing skills.
* Calculate candidate-job match scores.
* Generate suitability recommendations for recruiters.

### 💼 Job Matching

* Match candidate profiles with relevant job requirements.
* Identify suitable opportunities based on candidate skills and experience.

### 🎤 Interview Generation

* Generate candidate-specific interview questions.
* Support recruiters during the interview and evaluation process.

### 📊 Recruiter Dashboard

* Centralized recruitment overview.
* Candidate pipeline and recruitment activity.
* Candidate intelligence and evaluation insights.
* Easy navigation across recruitment modules.

## 🎯 Project Objective

The goal of CareerPilot AI is to improve the recruitment workflow by combining **AI-powered candidate analysis with structured recruiter evaluation**, helping reduce manual screening and supporting faster, more informed hiring decisions.

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/khushboo122003/CareerPilot-AI.git
```

### 2. Navigate to the project

```bash
cd CareerPilot-AI
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```
